❌ Backend won't start:
   • Make sure you're in the correct directory
   • Try: rm db.sqlite3 && ./setup_backend.sh

❌ Admin web shows "Network Error":
   • Check if backend (Terminal 1) is running
   • Check if you see http://localhost:8000 in Terminal 1

❌ Executive app shows blank screen:
   • Check browser console for errors (F12)
   • Check if backend is running
   • Try refreshing the page (Cmd/Ctrl + R)

❌ Port already in use:
   • Servers will auto-select next available port
   • Or kill process: lsof -ti:8000 | xargs kill -9 (replace 8000 with port)

❌ Can't login:
   • Double-check credentials (see login section above)
   • Check Terminal 1 for any backend errors
   • Try: ./setup_backend.sh to reset database
